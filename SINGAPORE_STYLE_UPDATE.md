# Singapore-style ShopTok homepage

This build updates the Shop page to closely follow the supplied TikTok Shop Singapore reference:
- left marketplace navigation
- category icon strip
- compact product/video horizontal carousels
- Savings for you / Top deals / Popular items / 4+ star deals / Best sellers
- search and category filtering
- responsive desktop/mobile layout
- existing ShopTok backend, database, auth, cart and seller functionality retained

The implementation uses ShopTok branding and the project's existing product data/assets rather than TikTok proprietary source code or trademarks.
